## <img src="assets/about_me.gif" width="45" alt="نبذة" /> نبذة عني

أنا **حمزة بن يونس (Hamza Ben Younes)** من تونس، مهتم بـ **ذكاء الأعمال وتحليل البيانات وتطوير البرمجيات المتكامل (Full-Stack)**. حصلت على **الإجازة في تطوير نظم المعلومات من المعهد العالي للدراسات التكنولوجية ببنزرت (2021–2024)** بتفوّق، وتابعت **دراسة الماجستير في ذكاء الأعمال والبيانات (2024–2026)**.

أهتم بتحويل البيانات إلى رؤى عملية باستخدام **Power BI وDAX وSQL وPython**، وبناء التطبيقات باستخدام **Java وSpring Boot وAngular وReact**. أنجزت مشروع تخرّجي بالتعاون مع **Medianet Consulting** حول منصة ذكية لإدارة الموارد البشرية لعدة شركات.

## 🎯 مجالات اهتمامي الحالية

- 📊 **تحليل البيانات وذكاء الأعمال:** لوحات مؤشرات تفاعلية، مؤشرات الأداء وإعداد التقارير.
- 🧠 **التعلّم المستمر:** خطوط ETL وSQL المتقدم وتعلّم الآلة وهندسة البيانات.
- 💻 **هندسة البرمجيات:** واجهات REST وتطبيقات الويب والحلول المعتمدة على البيانات.
- 🤝 **التعاون:** مشاريع تحليل البيانات والتطبيقات المدعومة بالذكاء الاصطناعي وتطوير الويب.
